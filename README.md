# Credit Scoring Model

Machine Learning project completed as part of my CodeAlpha internship.

## Objective

The objective of this project is to build a machine learning model for credit scoring and predict the credit risk of individuals based on relevant financial and demographic features.

## Dataset

The project uses two datasets:

- cs-training.csv - Training dataset
- cs-test.csv - Test dataset

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow

1. Data loading
2. Data preprocessing
3. Exploratory data analysis
4. Feature engineering
5. Model training
6. Model evaluation
7. Credit risk prediction
